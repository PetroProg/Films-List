# Films List 🎬

Минималистичное, сверхлегковесное веб-приложение и PWA для ведения личной коллекции фильмов в цветовой палитре **Catppuccin Mocha**.

Разработано для развертывания на локальном сервере с доступом по **HTTPS** через **Tailscale Serve**.

---

## ⚡ Особенности

- 🎨 **Catppuccin Mocha UI**: Эстетичный, чистый темный интерфейс на Tailwind CSS.
- 🪶 **Максимальная легковесность**: Бэкенд на **Go (Golang)** + SQLite без CGO (`modernc.org/sqlite`). Весь контейнер потребляет **~15–25 МБ RAM**!
- 📱 **PWA (Progressive Web App)**: Устанавливается как нативное приложение на смартфон (Samsung, iPhone) и десктоп, поддерживает быстрый доступ с домашнего экрана.
- 🎲 **«Что посмотреть сегодня?»**: Интерактивная рулетка для случайного выбора фильма из списка «В планах».
- 🔍 **Поиск и фильтрация**: Мгновенный поиск в реальном времени, фильтрация по статусам («Все», «В планах», «Просмотрено», «Брошено»), сортировка по названию, году, оценке и дате.
- ⭐ **Быстрые действия**: Оценка фильма от 1 до 5 звезд прямо с карточки в один клик; переключение статуса просмотра в один клик.
- 🔗 **Прямой переход**: Кнопка «Смотреть» для перехода по внешней ссылке (Rezka, Кинопоиск и т.д.).
- 📥 **Экспорт данных**: Выгрузка всей базы в CSV (совместим с Excel/Notion с UTF-8 BOM) или JSON одной кнопкой.
- 🚀 **Автоматическая инициализация**: При первом старте база автоматически наполняется начальным списком фильмов из `seed.csv`.

---

## 🛠 Технологический стек

- **Backend**: Go 1.23, Chi router, pure-Go SQLite (`modernc.org/sqlite`).
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Vite PWA Plugin.
- **Инфраструктура**: Multi-stage Docker, Docker Compose, Tailscale Serve (HTTPS TLS).

---

## 🚀 Развертывание

### 1. Локальный запуск через Docker Compose

```bash
docker compose up -d --build
```

Приложение будет доступно на `http://localhost:7070`.

### 2. Настройка HTTPS через Tailscale Serve

На сервере выполните:

```bash
tailscale serve --bg --https=7443 127.0.0.1:7070
```

Приложение станет доступно по защищенному HTTPS адресу:
`https://petroprog.tail703e6c.ts.net:7443`

```
├── Dockerfile          # Многоэтапная сборка (Node -> Go -> Alpine)
├── docker-compose.yml  # Декларация сервиса и лимит памяти (80 МБ)
└── seed.csv            # Базовые данные (160 фильмов)
```
